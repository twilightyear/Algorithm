### 🛠️ 풀이 접근 및 분석

-   **접근 1**
  - 가져갈수 있는 개수와 총 종류를 따로 구한뒤, 이를 통하여 논리적으로 가져갈 수 있는 개수가 총 종류보다 크다면 총 종류 전부 가져갈 수 있다는 것이니 총 종류를 반환하며, 반대로 가져갈 개수가 총 종류보다 적다면 내가 가져갈 수 있는 개수가 최대한으로 다양하게 가져갈 수 있는 최대값이다. 여기서 총 종류는 **Set** 을 이용한다면 쉽게 중복이 없는 총 개수를 구할 수 있었다.

### 📝 추후 개선점

  - 분명 쉬운 문제지만, 다른 사람들의 코드를 살펴보니 말도 안되게 간결한 풀이들이 상당했다. 아래의 코드를 압축하여 더 코드를 줄일 수 있지만 코드의 의미는 동일하다. 하지만 압축된 파이썬 코드의 방식이 더 파이썬다운 풀이방식이라고 생각하기에, 이러한 깔끔한 풀이법으로 풀이할 수 있는 역량을 길러야겠다고 생각했다.

### 💻 풀이 코드

```python
#풀이 1 (Set)
def solution(nums):
    answer = 0
    chance = len(nums) / 2 #가져갈 수 있는 개수
    count = len(set(nums)) #총 종류
    
    if chance <= count: #가져갈 개수 보다 종류가 많다면
        return chance
    else: #가져갈 개수보다 종류가 적다면 총 종류 개수 반환
        return count
```
