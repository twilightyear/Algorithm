### 🛠️ 풀이 접근 및 분석

-   **접근 1**
  - Deque 를 사용하여 쉽게 풀어보았다. prev 값을 두어 이전 값을 저장하며, for 문을 통한 arr 값의 순회 과정에서 prev 값과 동일하지 않은 경우에만 값을 추가해주었다. 물론 파이썬 기본 list 를 사용해도 되지만, 문제에서 배열의 크기는 최대 1000000 라고 했기에, 이렇게 큰 상황에 있어서는 Deque 가 유리하다고 판단했다. 이렇게 한다면 arr 의 길이 N 에 대하여 O(N) 의 시간복잡도와 공간복잡도를 가지게 된다.

### 📝 추후 개선점

  - 다른사람들의 풀이를 살펴보니 리스트의 슬라이싱을 사용해서 풀이를 한것을 볼 수 있었다. 슬라이싱을 통한 비교 및 스택 추가라는 아이디어인데, 정말 항상 그렇지만 다른사람들 풀이를 보며 배우는 것은 항상 많다고 생각한다. 접근 1번에서 마지막에서 결국 list 로 변환하는 과정에서 결국 시간과 공간이 소모되는데, 단편적인 부분만 보는 것이 아니라, 종합적인 부분을 본다면, 차라리 list 를 사용했다면 빨랐을 것이라고 생각한다.

### 💻 풀이 코드

```python
# 풀이 1 (Deque)
from collections import deque

def solution(arr):
    answer = deque()
    prev = None
    for i in arr:
        if prev != i:
            answer.append(i)
            prev = i
        
    return list(answer)
```
