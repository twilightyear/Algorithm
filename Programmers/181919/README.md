### [ Programmers ] 콜라츠 수열 만들기

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 콜라츠 수열은 반드시 **1** 로 수렴하게 된다는 가정이 존재하니 **while** 문에서 **n** 이 **1** 에 도달하기 전까지 루프를 반복하게 구성한 상태로 계산을 진행하게 한다면 해결이  가능하다고 판단했다.

### 📝 추후 개선점
  - 본 풀이에서, 삼항연산자로 조금 더 짧게 풀이가 가능할 수 있었다. 하지만 직관적인 풀이를 위해서는 지금 풀이의 길이가 적당한 길이를 가지는 코드라고 생각한다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(n):
    answer = [n]
    while(n!=1):
        if n % 2 == 0:
            n = n / 2
        else:
            n = n * 3 + 1
        answer.append(n)
    return answer
```
