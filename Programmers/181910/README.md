### [ Programmers ] 문자열 뒤의 n 글자

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
  - 문제가 원하는 부분은 문자열에 대한 슬라이싱 작업으로 한줄로 쉽게 계산이 가능하다. 슬라이싱을 하게된다면 복사된 문자열에 대하여 계산이 이루어짐으로, 문자열의 길이 N 에 대하여 최악의 경우, O(N) 의 시간복잡도와 O(N) 의 공간복잡도를 가지게 된다.

### 📝 추후 개선점
  - 현재 풀이는 단연 파이썬에서 최적의 풀이라고 생각한다. 시간복잡도와 공간복잡도의 개선이 더 크게 가능하지 않을 것이라고 말하고 싶다. 다만 다른 사람들의 풀이를 살펴보면, 대부분 나의 풀이와 동일하지만, [-n:] 을 사용하지 않고, len() 을 사용한 문자열 길이값에 n 을 빼기 연산하여, 이를 가지고 직관적으로 풀이를 진행한 코드가 존재했다. 이러한 쉬운 유형 말고 어려운 유형에 들어갔을때, 이처럼 효율적인 풀이가 존재하는데 굳이 다른 방식으로 삽질을 하지 않기 위해서는 수많은 노력이 필요하다고 생각한다.

### 💻 풀이 코드

```python
# 풀이 1 (List)
def solution(my_string, n):
    return my_string[-n:]
```
