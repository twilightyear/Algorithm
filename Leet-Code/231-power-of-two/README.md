# [LeetCode] 231. Power of Two
---
### 📌 문제 링크
[LeetCode - 231. Power of Two](https://leetcode.com/problems/power-of-two/description/?envType=problem-list-v2&envId=math)
---
### ⚠️ 제약조건
- -231 <= n <= 231 - 1
---
### 🛠️ 풀이 접근 및 핵심 로직
- 처음 접근은 이진수로 접근했다. 이진수의 처리를 String 으로 처리하여 음수인 경우는 볼 필요도 없이 False 를 반환하고 이외의 경우에서는 앞의 0b 를 제거하고 뒤의 자리수를 integer로 변환하여 더했을 경우 1이 아니라면 2의 제곱수일수 없다는 점을 사용했다. 2의 제곱수라면 이진수의 형태에서 1이 1개만 존재하고 나머지는 0으로 채워져 있어야 한다는 특성을 사용한 것이다.
---
### 📊 복잡도 분석
**시간복잡도**

- 이진수로 바꿀 경우에서 시간복잡도는 O(log2 n) 이 된다. 루프를 n번 도는것이 아니라 결국 이진수의 자릿수만큼만 돌기 때문이다. 이외의 연산에서 O(1)의 시간복잡도가 발생하지만 결론적으로는 총 O(log2 n) 의 시간복잡도를 할 수 있다.

**공간복잡도**

- 시간복잡도랑 동일한 원리로 공간복잡도는 O(log2 n) 이 된다. 
---
### 📝 회고 / 추후 개선점
- 하지만 위의 풀이법은 다소 다른 사람들과의 풀이보다는 느린 성능을 보였다. 비트를 문자열로 처리한 것에서 다소 느린 성능을 보인 것이였다. 그렇기에 다른 풀이를 이해해본 결과, 0보다 작은 경우의 처리는 동일하지만, 비트의 처리에 있어서 n AND n-1 를 통하여 비트의 오른쪽부터 시작해서 처음 만나는 1을 없애는 과정을 넣고 이후 값이 0이라면 더이상 1이 없으며, 결론적으로 1이 1개라는 특성을 이용할 수 있었다.

- 비트로 접근하려는 의도는 좋았지만 비트의 처리에서 비효율적으로 문자열로 처리한 것을 기억하고 추후에는 이러한 점을 꼭 기억해야할 것이다.
