# [LeetCode] 217. Contains Duplicate
---
### 📌 문제 링크

[LeetCode - 217. Contains Duplicate](https://leetcode.com/problems/contains-duplicate/description/?envType=problem-list-v2&envId=rr2ss0g5)

### ⚠️ 제약조건
- 1 <= nums.length <= 105
- -109 <= nums[i] <= 109
---
### 🛠️ 풀이 접근 및 핵심 로직
- **중복** 이라는 개념과 밀접하게 관련이 있는 **Set**, 집합이라는 개념이 먼저 떠올랐다. 그렇기에 **Set** 을 사용하여 데이터를 추가 및 검증하는건 어떤가 하는 생각이 들었다. 물론 기존 **Array** 를 사용해도 동일한 로직으로 구현이 가능하겠지만, **Array** 는 인덱스를 전부 조회해봐야한다는 점에 있어서 **Set** 이 시간복잡도 측면에서 해당 자료구조를 활용하는것 보다 좋을 것이라고 판단했다.
---
### 📊 복잡도 분석
**시간복잡도**

- 원본 데이터의 개수 **N** 에 대하여 **N** 번 모두 한번씩은 방문하여 **Set** 에 있는지 여부를 확인한다. 방문에 있어서는 **O(N)** 의 시간복잡도를 가지며, **Set** 에 있는지 비교에 있어서는 **Hash Table** 로 구현되어있는 **Set** 의 원리상 **Hash 충돌** 과 같은 경우를 제외하면 **O(1)** 의 시간복잡도를 가진다. **Hash 충돌** 은 쉽게 설명하자면 임의의 값 **A** 와 **B** 가 있을때, **A** 를 **Hash** 변환하고 **B** 를 **Hash** 변환하였다고 했을때 이 **Hash** 값에 해당하는 주소에 데이터를 저장해야하는데 동일한 주소에 저장하려고 하다보니 문제가 발생하는 경우이다. 

- 아무튼 결론적으로 **O(N)** 의 시간복잡도를 가진다고 할 수 있다.

**공간복잡도**

- 원본 데이터의 개수 **N** 개에 대하여 최악의 경우 **N** 개의 데이터는 전부 다르다고 할 수 있다. 이러한 경우에서 **Set** 은 **N** 개의 데이터를 저장해야하는데, 이는 **O(N)** 의 공간복잡도를 가지게 한다.

---
### 📝 회고 / 추후 개선점
- 문제를 풀어서 제출을 해보니, 생각 이외로 다른 사람들보다 낮은 성능을 보였다는걸 알게 되었다. 높은 성능을 기록한 코드를 살펴보니 정말 당황했다.



```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        return not len(nums) == len(set(nums))
```

- 본 코드에서는 원본 데이터의 개수와 **set** 을 사용하여 변환한 데이터에 대한 데이터 개수를 비교하여 중복이 있느냐 없느냐만 정말 빠르고 간편하게 확인한 것을 확인할 수 있었다. 결국 내가 만든 코드의 완전 축약형 버전인 것이다.

- **len()** 함수 특성상 데이터의 개수는 전부 확인하니 데이터의 개수 N개에 대하여 **O(N)** 의 시간복잡도를 가지며, **set** 변환에 있어서도 결국 **O(N)** 의 시간복잡도를 가지며, 공간복잡도도 마찬가지로 동일하여 시간/공간복잡도의 단순 수치적 비교로는 차이점이 없어 보인다.

- 하지만 여러가지 이유 때문에 성능차이가 발생할 수 있다는 것을 파악할 수 있었다.

- 먼저 **오버헤드** 문제이다. **for** 문과 **if** 문을 통하여 하나하나 확인하는 과정에서 **오버헤드** 가 발생하여 상대적으로 추가적인 공간/시간 낭비가 발생할 수 있다. 이외에도 내장 함수의 경우에서는 한번에 사용하면 효율적으로 처리를 내부적으로 진행하지만, 초기화하여 하나하나 추가하는 과정을 만들어둔다면 내부적으로 만들어둔 특혜를 이용할 수 없게 되는 것이다.

- 이러한 여러가지 이유를 통하여 성능차이가 발생할 수 있다는 점과 사고의 방향성을 반성해볼 수 있는 시간이 되었던 것 같다. 핵심을 정확하게 파악하여 보다 효율적인 코드 작성능력의 개선이 필요하다.
